# 公式标记规范（Formula Markup v1）

> 适用范围：DSH Remote（安卓 App）里**一切会被渲染或导出的文本**——聊天消息、
> Markdown 文档、`.txt`、`.docx`、`.xlsx` 单元格。
> 一句话：用它包起来的内容，App 会**尝试当作公式**处理（排版渲染 + 导出成
> Word 原生公式），而不是当普通文字。

---

## 1. 语法

```
/"TeX 源码"/
```

- **开**：`/` 紧接 `"`（或 `“`）
- **闭**：`"`（或 `”`）紧接 `/`
- 中间是 **TeX 数学源码**

### 输入容错（中文输入法友好）

中文输入法下直接敲 `/` 与 `"` 常常打出全角斜杠与弯引号。以下写法**全部等价**，
都会被识别（这是刻意设计的容错，不是巧合）：

| 位置 | 接受的字符 |
|---|---|
| 斜杠 | `/` (U+002F)、`／` (U+FF0F) |
| 开引号 | `"` (U+0022)、`“` (U+201C)、`”` (U+201D) |
| 闭引号 | `"` (U+0022)、`”` (U+201D)、`“` (U+201C) |

所以下面四种写法都能渲染出同一个公式：

```
/"\varphi=\frac{1+\sqrt5}{2}"/
/“\varphi=\frac{1+\sqrt5}{2}”/
／"\varphi=\frac{1+\sqrt5}{2}"／
／“\varphi=\frac{1+\sqrt5}{2}”／
```

### 两种形态（同一个标记，按位置判定）

| 写法 | 形态 | 呈现 |
|---|---|---|
| 标记**独占一行**（前后只剩空白） | 显示式 | 居中、独占一块，超宽可横向滚动 |
| 标记**夹在正文中** | 行内式 | 与文字基线对齐，随文排版 |

```
下面这个结果来自部分分式分解：

/"\int\frac{dx}{x^5+1}=\frac15\ln|x+1|+\frac{\ln\left(x^2-\varphi x+1\right)}{10\varphi}+C"/>

其中 /"\varphi"/ 是黄金比。
```

---

## 2. 转换语义（「尝试」的含义）

被标记的内容会依次尝试：

1. **解析为 TeX** → 成功则按数学排版渲染（KaTeX 级：分式、根式、积分号、
   上下限、希腊字母、矩阵、定界符自适应等）。
2. **导出 `.docx` 时** → 写成 **OMML**，即 Word 里 `Alt` + `=` 那种**原生可编辑
   公式**（不是图片，也不是 LaTeX 纯文本）。`\boxed{…}` 会变成带边框的公式。
3. **解析失败或渲染异常** → **原样显示标记内的文字**（等宽 + 浅底）。
   绝不吞内容，最多是「没那么好看」。

因此**纯算式也直接可用**，不要求严格的 LaTeX：

```
/"1/2 + 3/4 = 5/4"/
/"x^2 + y^2 = r^2"/
/"123456"/
```

---

## 3. 优先级

从高到低：

1. **代码**：反引号 `` `…` `` 与围栏代码块 ` ``` ` 内部**不解析**任何公式标记
   （这样才能用代码展示公式语法本身）。
2. **本标记** `/"…"/`：显式意图，优先于一切启发式判断。
3. `$$…$$` / `\[…\]`：显示式公式。
4. `$…$` / `\(…\)`：行内公式（带误报防护：不把「价格 $5 到 $10」当公式）。

> 既有 `$…$` 语法继续可用（向后兼容），但**推荐新标记**：`$` 在中文输入法下要
> 切键盘、在 shell 脚本与价格里歧义大，而 `/"…"/` 可以直接用中文输入法打出。

---

## 4. 不误报保证

规范明确排除了这些场景：

| 输入 | 结果 |
|---|---|
| 路径 `C:/Users/Administrator` | 普通文字 |
| 链接 `http://example.com/a/b` | 普通链接 |
| 散文里的引号 `他说 "你好" 然后走了` | 普通文字 |
| `/""/`（空内容） | 普通文字（不识别） |
| 漏写闭标记 `/"a+b 后面还有很长的正文…` | **整段保留为普通文字**（不吞内容），跨行搜索上限 4000 字符 |
| 代码块 / 反引号内的标记 | 原样字面显示 |

## 5. 完整示例

```markdown
# 一元五次分式积分

下面这条公式用标记包裹（独占一行 → 显示式）：

/"\boxed{\;\int\frac{dx}{x^5+1}=\frac15\ln|x+1|+\frac{\ln\left(x^2-\varphi x+1\right)}{10\varphi}-\frac{\ln\left(x^2+\varphi^{-1}x-1\right)}{10\varphi^{-1}}+C\;}"/>

行内写法：设 /"\varphi=\frac{1+\sqrt5}{2}"/ 为黄金比，则 /"\varphi^2=\varphi+1"/。

代码里的标记不会解析（用来讲解语法本身）：写法是 `/"…"/` 这样。

| 项目 | 值 |
|---|---|
| 黄金比 φ | /"\varphi"/ |
```

在 App 里：显示式公式居中排版；行内公式随文；表格单元格里的公式同样渲染。
导出 Word 后，以上公式全部成为可 `Alt`+`=` 编辑的原生公式。

## 6. 实现位置（单一事实来源）

| 关注点 | 文件 |
|---|---|
| 定界符识别（**唯一实现**） | `lib/math/tex.dart` → `findMathSegments()` / `formulaMarkupWholeLine()` |
| 渲染（KaTeX 级） | `lib/math/view.dart`（`flutter_math_fork`） |
| LaTeX → Word 原生公式（OMML） | `lib/math/omml.dart` |
| 聊天消息渲染 | `lib/md.dart` |
| 文档（md/txt/docx/xlsx）解析 | `lib/docs/*.dart` |
| `.docx` 导出 | `lib/docs/docx_writer.dart` |
| **规范的可执行版本（测试）** | `test/formula_markup_test.dart` |

> **规范与实现不允许漂移**：改规范必须同步改测试与实现；三者的对应关系是
> 「本文档 ↔ `test/formula_markup_test.dart` ↔ `lib/math/tex.dart`」。
